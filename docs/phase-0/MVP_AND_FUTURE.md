# MVP vs Future Scope

## MVP direction

- Real authentication
- Persistent profile/onboarding
- Product retrieval
- Camera/gallery capture
- Real analysis service boundary
- Honest recommendation/routine states
- Session/logout correctness
- Basic security/privacy controls

## Future / optional

- Advanced AI personalization
- Long-term progress analytics
- Climate-aware recommendation sophistication
- Reminders/notifications
- Social login providers
- Rich analytics/telemetry
- Offline-first synchronization

Phase 1 implements none of these product capabilities; it creates the structure they will use.
